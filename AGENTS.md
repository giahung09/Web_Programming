# Project rules — cartTotal

## Stack and scope
- Use plain JavaScript with Node.js ES modules and built-in Node APIs only.
- Keep the implementation in `src/cart.js` and behavior tests in `test/cart.test.js`.
- Treat `README.md` as the source of truth for `cartTotal(items, options)`.

## Commands
- Run `npm test` to check behavior.
- Run `npm run format:check` to check JavaScript syntax and formatting.

## Conventions
- Use two-space indentation, single quotes, no semicolons, and a final newline.
- Add focused tests for each behavior or edge case changed.
- Inspect the diff before considering the work complete.

## Never
- Never add a third-party dependency for this assignment.
- Never alter the specification or weaken a test to conceal a failing implementation.
